# LifeLink – Specific Disease Ambulance Dispatch System

A web-based ambulance dispatch system designed to connect patients,ambulance and drivers, helping streamline emergency ambulance booking, dispatch coordination, and patient transportation.

## Project Overview

LifeLink – Specific Disease Ambulance Dispatch System is a web application designed to simplify the ambulance booking and dispatch process. The system aims to help patients request emergency transportation, coordinate ambulance assignments, and connect with suitable hospitals.

The project focuses on improving emergency response coordination through a centralized platform for patients, ambulance drivers, and administrators.

## Project Objectives

* Simplify emergency ambulance booking.
* Connect patients with ambulance drivers and hospitals.
* Support ambulance assignment based on availability and location.
* Improve coordination between patients, drivers, and administrators.
* Provide a centralized interface for managing emergency requests.
* Support timely access to emergency transportation.

## Key Features

* **Patient Management:** Supports patient access and emergency booking workflows.
* **Emergency Booking:** Allows users to submit ambulance requests.
* **Ambulance Dispatch:** Supports ambulance assignment and booking coordination.
* **Hospital Management:** Provides hospital-related registration and management functionality.
* **Driver Management:** Supports ambulance driver information and dispatch operations.
* **Location Tracking:** Designed to support ambulance location tracking.
* **Admin Dashboard:** Provides a centralized interface for managing system activities.
* **Notifications:** Supports emergency-related notifications where implemented.

## Technologies Used

* **Backend:** Python and Flask
* **Frontend:** HTML, CSS, and JavaScript
* **Database:** MySQL
* **Mapping:** Leaflet.js and OpenStreetMap
* **Authentication:** Flask sessions

## System Modules

### 1. Patient Module

Provides the patient-facing interface for accessing the system and requesting ambulance services.

### 2. Ambulance and Driver Module

Supports ambulance and driver management and the ambulance dispatch workflow.

### 3. Admin Module

Provides administrative functionality for managing users, bookings, drivers, ambulances, and related records.

### 4. Tracking and Notifications Module

Designed to support location tracking and emergency notifications, depending on the implemented functionality.

## How to Run the Project

1. Clone or download this repository.
2. Install Python and MySQL if they are not already installed.
3. Open the project folder in Visual Studio Code.
4. Create and activate a Python virtual environment.
5. Install the required dependencies listed in `requirements.txt`.
6. Configure the database connection using your local MySQL settings.
7. Create and initialize the required database tables.
8. Run the Flask application using app.py(entry point of the project).
9. Open the local address displayed in your terminal in a web browser.
